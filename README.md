# opencode

Personal [opencode](https://opencode.ai) configuration — rules, skills, agents, and behavior guidelines.

## Structure

- `AGENTS.md` — Agent behavior and engineering lifecycle
- `opencode.json` — Provider, MCP, LSP, and permission config
- `rule/` — Domain-specific rules (Python toolchain, testing, git, web search)
- `skills/` — Reusable skill pipelines (cleanup → refactor → review)
- `agents/` — Subagent definitions (code-reviewer)
